## 目标

voice 渠道 Agent 回复改**分段合成 + 边播边预合成**：第 1 句合成完立即出声，后续句子边播放边合成——把「等全文合成完才播」的等待感砍掉一大截，向网页端流式朗读体验看齐。

### 关键设计决策

1. **对照移植而非凭记忆重写**：先完整读取网页端 `chooseTtsCut` 源码，逐行对照移植到 Python，切句规则完全一致
2. **单段走原路径**：`len(segments) <= 1` 时不走 `_play_segments`，直接 `synthesize → play_audio`，与改前行为完全一致
3. **并发上限 2 + 预合成**：`asyncio.Semaphore(2)` 限制同时最多 2 个 `synthesize` 在途；播放第 i 段时启动第 i+2 段的合成任务
4. **失败语义分层**：合成失败→仅该段降级文字（`_emit`），后续段继续；播放失败→当前及后续段全部降级文字
5. **player.py 零改动**：`play_audio` 保持单段契约，分段调度在 voice.py 内组合
6. **兼容性**：`[END]` 剥离在分段前、`max_voice_chars` 超长回文字在分段前、唤醒回应不走分段、每段过 DSP、静默退出/连续对讲续听不变
7. **切句阈值微调**：`_FIRST_STRONG_MIN` 从 8 降到 5、`_FIRST_FALLBACK_MIN` 从 16 降到 12，适配 voice 渠道短口语回复
