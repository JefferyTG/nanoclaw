# 帮用户做决定

> 本技能只规定**行为机制**，不规定**说话风格**。语气、口吻、自称等由当前人设决定，请始终用你当前的人设风格回应。

## 什么时候用

- 用户抛出 2 个及以上选项，明显在犹豫、求建议、或让你"帮选一个"。
- 例子：「中午吃啥」「这两个方案选哪个」「先写文档还是先写代码」。

## 怎么做

1. **确认选项**：先把用户给的选项整理清楚。如果用户没给全（比如只说"帮我选"），
   先追问一句要到清单——保持简洁，别啰嗦。
2. **调用 exec 做随机**：用 `exec` 工具跑一段 python，让机器来选，显得真·随机而不是你偏心：

   等权随机（把选项放进列表）：

   ```bash
   python3 -c "import random; opts=['选项A','选项B','选项C']; print(random.choice(opts))"
   ```

   带权重（weights 与 opts 一一对应，数字越大越容易被选中）：

   ```bash
   python3 -c "import random; opts=['选项A','选项B']; w=[3,1]; print(random.choices(opts, weights=w, k=1)[0])"
   ```

   把用户真实的选项文本替换进去即可。
3. **用你当前的人设语气公布结果**：别干巴巴甩一个词，结合你的人设加点温度或气场。
   下面只是"通用结构"示例，措辞请按你的人设改写：

   - 「别纠结了，听我的——今天就吃**火锅**。去吧。」（坚定型人设示例）
   - 「两个都行，但既然你让我选，那我拍板：**方案 A**。」（决策型人设示例）
4. 如果用户给了权重或偏好，结果出来后可以顺带圆一句，让决定显得有道理。

## 注意

- 只帮做**低风险、可逆**的日常决定。涉及钱、健康、不可逆的操作，别替用户拍板，
  给建议让他自己定。
- 随机就是随机，别假装你有高深理由——偶尔俏皮地表示"就是随便点的，不服重抽"
  反而更讨喜（具体语气按你的人设）。
- 选项为空或只有一个时，直接提醒用户「这没得选啊」，别硬跑脚本。
